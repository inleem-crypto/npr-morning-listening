# AI 문맥 검토 연결 및 비용 확인

자동 생성 작업은 음성 전사 후 `scripts/review_meanings.py`를 실행합니다.
공개 뉴스의 문제와 전후 문맥을 OpenAI Responses API로 한 번에 보내
한국어 의미 단서와 출제 적합성을 검토합니다. 앱의 요약 메모와 개인 답안은
보내지 않습니다. 음성·시간·정답을 AI가 수정하지 못하도록 검증합니다.

## 최초 연결

1. ChatGPT Business 워크스페이스 소유자 계정으로 워크스페이스 결제 설정의
   API credits 혜택을 확인하고, 본인이 소유한 API 조직에 연결합니다.
   [공식 크레딧 안내](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)
   에 따르면 대상 구독은 활성화가 필요하며, 활성 크레딧만 사용하려면 API
   결제 수단을 추가할 필요가 없습니다. 이 저장소는 혜택 대상 여부나 크레딧
   잔액을 자동으로 조회하지 못합니다.
2. 해당 API 조직의 프로젝트에서 API 키를 만듭니다.
3. 이 GitHub 저장소의 **Settings → Secrets and variables → Actions →
   New repository secret**에서 `OPENAI_API_KEY`라는 이름으로 저장합니다.
   키를 채팅, 저장소 파일, HTML 또는 학습 앱의 입력란에 넣지 않습니다.
4. **Actions → Prepare daily dictation lesson → Run workflow**로 시험합니다.
5. 앱의 **문맥 검토 및 API 사용량**을 펼쳐 확인합니다.
   `AI 문맥 검토 완료`가 표시되어야 실제 검토가 실행된 것입니다.

## 초기 비용 제한

- 모델: `gpt-5.6-terra`, 추론 강도 `none`.
- 한국 날짜 기준 하루 최대 API 호출 1회. 성공 결과는 재사용합니다.
- 이 저장소의 작업에 월 **추정 $1.00** 한도 적용.
- 요청 UTF-8 바이트 수에 여유분을 더해 입력 토큰의 보수적인 상한을 잡고,
  출력은 최대 2,200토큰으로 제한합니다. 호출 전 최대 예상액을 예약합니다.
- 사용량을 응답에서 확인하면 예약액을 실제 토큰에 따른 추정액으로 바꿉니다.
  타임아웃·사용량 미확인 시에는 예약액을 유지합니다. 자동 재시도하지 않습니다.
- 검토가 실패하면 기존 학습자료를 보존합니다. 적합하지 않다고 판정된 문제는
  제외하되, 모든 문제가 탈락하면 이전 자료를 보존합니다.
- 모델이 원음을 듣고 검증하는 것은 아닙니다. 전사 오류가 있으면 의미 검토에도
  오류가 생길 수 있습니다.

단가는 2026-11-16 [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-terra)
기준 입력 100만 토큰당 $2, 출력 $12입니다. 변경되면 코드 단가도 갱신해야 합니다.

`ai-usage-ledger.json`은 호출·토큰·추정 사용액과 불확실한 호출의 예약액을 기록합니다.
`ai-review-status.json`은 앱에 표시할 상태와 월 집계를 담습니다. 키나 원시 API
응답은 두 파일에 기록하지 않습니다. 사용량 기록이 손상되면 호출을 차단합니다.

**이 한도는 이 저장소의 추정 사용액에 대한 제한이며, API 조직 전체의 결제 한도가
아닙니다.** 가격 변경, 작업 강제 취소 전 기록 미반영, 다른 앱의 API 사용 등은 별도로
확인해야 합니다. 토큰 사용액이 무료 크레딧에서 차감됐는지와 실제 현금 청구액은 API
조직의 Usage/Billing에서 확인합니다. 이 앱은 무료 사용을 확인하지 못한 상태에서
‘무료’라고 표시하지 않습니다.

## 중지

GitHub **Settings → Secrets and variables → Actions → Variables**에서
`NPR_AI_REVIEW_ENABLED`를 `false`로 설정하면 다음 작업부터 API 검토를 중지합니다.
다시 켜려면 `true`로 바꿉니다. 기존 음성 전사와 학습자료 생성은 계속 동작합니다.
